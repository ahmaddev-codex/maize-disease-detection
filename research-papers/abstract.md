# Abstract

## MaizeGuard: Real-Time Maize Disease Detection for Nigerian Smallholder Farmers Using Deep Learning, Multimodal Fusion, and Offline-First Mobile AI

---

Maize (*Zea mays*) production in Nigeria — the country's most widely cultivated cereal, with annual output exceeding 11 million metric tons — faces annual yield losses of 20–40% attributable to three fungal pathogens: Northern Corn Leaf Blight (NCLB, *Exserohilum turcicum*), Common Rust (*Puccinia sorghi*), and Gray Leaf Spot (GLS, *Cercospora zeae-maydis*). The primary driver of this loss is not the unavailability of effective fungicide treatment but the absence of timely, accurate field diagnosis. Nigeria's agricultural extension system serves an estimated ratio of one officer per several thousand smallholders, leaving the majority of farmers dependent on unreliable visual self-assessment. Published AI disease detection systems further compound this gap by performing well under controlled laboratory conditions yet degrading substantially under field conditions characterised by variable natural light, consumer-grade cameras, and complex backgrounds.

This work presents MaizeGuard, a complete, deployable AI system designed to address these failures. The core classifier is an EfficientNetB3 convolutional neural network trained on 4,186 PlantVillage maize images across four classes (NCLB, Common Rust, GLS, Healthy) using two-stage transfer learning with class-weighted training to manage dataset imbalance. Two quantised models are exported from the same checkpoint: FP16 (23.3 MB), which scores 93.15% on the held-out test split of 628 images, and INT8 (13.5 MB), which scores 87.74% on the same split. The application loads FP16 first and falls back to INT8, since the 9.8 MB saved does not justify a 5.4-point loss. Per-class F1 is uneven — Healthy 1.00 and Rust 0.97 against GLS 0.79 under FP16 — and Gray Leaf Spot remains the weakest class. All figures are produced by `src/phase4_edge/evaluate_tflite.py` and recorded with the model hashes in `models/exports/metrics.json`; on-device latency has not yet been measured and no figure is claimed here. A late-fusion multimodal extension that incorporates OCR-extracted crop variety metadata is implemented but experimental: no public dataset pairs leaf photographs with the variety of the same plant, the metadata used in training is synthetic, and the accompanying ablation is reported in Chapter 4 rather than as an accuracy gain.

MaizeGuard is deployed as a cross-platform Flutter mobile application in which diagnosis runs entirely on the device: classification, the built-in agronomic guidance, the scan history and the map layer require no connectivity, while generated advice and Nigerian-language speech require a network and a user-supplied API key. The application integrates live-camera leaf classification, OCR seed label scanning with inline field correction, GPS-tagged scan history, and geospatial disease mapping via OpenStreetMap. A built-in rule-based engine provides treatment guidance naming active ingredients rather than brands, with dose, pre-harvest interval and protective equipment referred to the product label and to an extension officer. Where a key and a connection exist, a single cloud provider (Groq) generates a longer advisory; there is no provider chain. The result screen always states which produced the text on screen — the model that answered, or the built-in rules and why — and the advice is stored with the scan so that reopening it neither repeats the request nor changes the wording. A four-language system — English, Yoruba, Igbo, and Hausa — generates advice in the farmer's chosen language, with Nigerian-language speech delivered via the YarnGPT API (voices: Idera for Yoruba, Chinenye for Igbo, Zainab for Hausa) and a fallback to whatever voice the device itself has installed.

Additional features addressing practical field use include: a confidence gate displaying an amber warning banner when model confidence falls below 0.60, offering an immediate retake and withholding any chemical recommendation until the diagnosis is confirmed; a scan feedback loop enabling farmers to record whether a diagnosis was correct, with responses stored for future model improvement; and a unified result screen presenting the complete diagnostic consultation — disease verdict, on-device treatment recommendations, AI-enhanced advice, language-specific translation, and feedback prompt — on a single scrollable view without requiring navigation to secondary screens. Field-scale aerial monitoring is supported via a UAV pipeline that applies sliding-window inference to drone orthomosaic imagery and generates interactive disease heatmaps. The classifier it applies is the same leaf model, trained and measured on close-up photographs and never evaluated on imagery taken at altitude; the heatmap is therefore presented as a scouting aid for deciding where to walk, not as a diagnosis of the plants it colours.

MaizeGuard's on-device diagnosis, Nigerian-language accessibility, contextual agronomic specificity, and its explicit reporting of where each piece of advice came from distinguish it from generic plant disease classification applications. Its measured limits are stated rather than elided: the training and test data are laboratory photographs from PlantVillage, so no field-condition accuracy is claimed here; Gray Leaf Spot is the weakest class; and the multimodal extension awaits a paired dataset that does not yet exist. The system's open design — standard TFLite inference, open-source Flutter framework, OpenStreetMap tiles — ensures maintainability and reproducibility without proprietary infrastructure dependencies, positioning MaizeGuard as both a practical decision-support tool for Nigerian smallholder farmers and a replicable reference architecture for agricultural AI deployment in low-connectivity, resource-constrained environments.
