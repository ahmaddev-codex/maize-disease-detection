# Abstract

## MaizeGuard: Real-Time Maize Disease Detection for Nigerian Smallholder Farmers Using Deep Learning, Multimodal Fusion, and Offline-First Mobile AI

---

Maize (*Zea mays*) production in Nigeria — the country's most widely cultivated cereal, with annual output exceeding 11 million metric tons — faces annual yield losses of 20–40% attributable to three fungal pathogens: Northern Corn Leaf Blight (NCLB, *Exserohilum turcicum*), Common Rust (*Puccinia sorghi*), and Gray Leaf Spot (GLS, *Cercospora zeae-maydis*). The primary driver of this loss is not the unavailability of effective fungicide treatment but the absence of timely, accurate field diagnosis. Nigeria's agricultural extension system serves an estimated ratio of one officer per several thousand smallholders, leaving the majority of farmers dependent on unreliable visual self-assessment. Published AI disease detection systems further compound this gap by performing well under controlled laboratory conditions yet degrading substantially under field conditions characterised by variable natural light, consumer-grade cameras, and complex backgrounds.

This work presents MaizeGuard, a complete, field-deployable AI system designed to address these failures. The core classifier is an EfficientNetB3 convolutional neural network trained on 4,188 PlantVillage maize images across four classes (NCLB, Common Rust, GLS, Healthy) using two-stage transfer learning with class-weighted training to manage dataset imbalance. Post-training INT8 quantisation compresses the model from 47 MB to 13 MB, achieving 89.2% test accuracy with less than 1% degradation from the float32 baseline and inference latency of approximately 850 milliseconds on mid-range Android hardware. A late-fusion multimodal extension that incorporates OCR-extracted crop variety metadata — read from seed bag label photographs using Google ML Kit Text Recognition — raises accuracy to approximately 95.8% for scans where variety information is available.

MaizeGuard is deployed as a cross-platform Flutter mobile application that operates fully offline. The application integrates live-camera leaf classification, OCR seed label scanning with inline field correction, GPS-tagged scan history, and geospatial disease mapping via OpenStreetMap. An on-device rule-based recommendation engine provides actionable treatment guidance referencing Nigerian agro-dealer fungicide brands, growing-season timing, and variety-specific susceptibility data from IITA Nigeria. In connected environments, a three-tier cloud advisory chain augments this guidance: Gemini 2.0 Flash serves as the primary AI provider, with automatic silent failover to Groq (`llama-3.3-70b-versatile`) on any failure, and final fallback to the on-device engine as a guarantee of service continuity. A four-language system — English, Yoruba, Igbo, and Hausa — enables AI advice generation in the farmer's chosen language, with authentic Nigerian-language text-to-speech output delivered via the YarnGPT API (voices: Idera for Yoruba, Chinenye for Igbo, Zainab for Hausa) and device-native synthesis for English.

Additional features addressing practical field use include: a confidence gate displaying an amber warning banner when model confidence falls below 60%, with guidance on retaking the scan under improved lighting and framing conditions; a scan feedback loop enabling farmers to record whether a diagnosis was correct, with responses stored for future model improvement; and a unified result screen presenting the complete diagnostic consultation — disease verdict, on-device treatment recommendations, AI-enhanced advice, language-specific translation, and feedback prompt — on a single scrollable view without requiring navigation to secondary screens. Field-scale aerial disease monitoring is supported via a UAV integration pipeline that applies sliding-window inference to drone orthomosaic imagery and generates interactive HTML disease heatmaps for spatial outbreak detection at the farm level.

MaizeGuard's offline-first architecture, Nigerian-language accessibility, contextual agronomic specificity, and layered AI reliability distinguish it from generic plant disease classification applications. The system's open design — standard TFLite inference, open-source Flutter framework, OpenStreetMap tiles — ensures maintainability and reproducibility without proprietary infrastructure dependencies, positioning MaizeGuard as both a practical decision-support tool for Nigerian smallholder farmers and a replicable reference architecture for agricultural AI deployment in low-connectivity, resource-constrained environments.
